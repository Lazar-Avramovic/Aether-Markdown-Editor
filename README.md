# Aether — Liquid Glass Markdown Editor

A nice little desktop app that just does markdown, looks beautiful, and stays out of your way.

## What it does
- Real-time side-by-side markdown preview.
- Fluid folder navigation (toggle between Stack and Tree view).
- Frosted glass design with custom light/dark theme modes.
- Supports running multiple instances/windows safely without locking profile cache database errors.

## How to run it from source
1. Install dependencies:
   ```bash
   npm install
   ```
2. Launch the app:
   ```bash
   npm start
   ```

## Packaging
To package it into a standalone `.exe`:
```bash
npm run build
```
